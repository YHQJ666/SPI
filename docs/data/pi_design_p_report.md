## 单 P 为什么不满框

单 P 的环路只是 `L = KDC·Plant`：`GM = |P(fc)|dB − |P(f_gm)|dB`（f_gm = plant 自己的 −180° 点，3112 Hz），`PM = 180 + φp(fc)`。两个约束各自能占的 fc 区间刚好错开：

| 约束 | 允许的 fc | 另一项在那里的值 |
|---|---|---|
| GM ≥ 5 dB | ≤ 2096 Hz | PM = 64.0° |
| PM 45–60° | 2181–2269 Hz | GM = 4.59–4.87 dB |

所以框内没有交点；要 GM > 5 dB 只能上 PI（见 `pi_design_pi_report.md`）。

## 注意

1. 单 P 没有积分，低频没有额外增益，50 Hz 跟踪靠 plant 的 15.5 dB 直流增益 + KDC，会留静差。
2. 单 P 的 GM、PM 都被 plant 绑死，两个窗口错开，框内无解；要 GM > 5 dB 只能上 PI。
3. 数据 2.1–3 kHz 的相位有卷绕/噪声，PM 在 2 kHz 以上只能参考。
4. 上板后建议再扫一次 SFRA 复核。
